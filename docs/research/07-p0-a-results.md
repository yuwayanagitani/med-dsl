## 実装した範囲

| 部分 | 動作 |
| --- | --- |
| ライブラリ | `med_dsl.evaluate(request)` が入力を変更せず JSON 相当の結果を返す |
| CLI | request または `--fixture` 指定の草案例を読み、結果を JSON で返す。expected は処理関数へ渡さない |
| 参照 | request 内のパッケージ・依存版・SHA-256 を照合。同じ参照への異なる実体、未解決依存、述語の所有者衝突を拒否 |
| 結合 | 一つの文脈内の正の atom を役割順で照合。同名変数を共有し、binding と根拠を集合として返す |
| 時点・確認・訂正 | 参照時点までの主張と人の確認記録を使う。明示的な訂正関係で旧主張を現採用から外し、訂正の連鎖で古い主張を復活させない |
| 否定・衝突 | ground atom の明示的な否定を検索。同文脈の肯定・否定の衝突では確定回答を止め、双方の根拠を返す |
| 未知の意味 | 可視主張が必要とする未知能力があれば、その文脈を unassessed にする |
| 上限 | サイズ・件数・照合ステップ・binding 上限を確認。未完了一問の途中 binding を完全回答にしない |

参照の固定は、今回渡した request の依存閉包と出力の入力ハッシュの範囲です。別々の request に同じ名前で異なるパッケージを持ち込んだことを検出する永続的なレジストリは、まだありません。確認記録の本人性も認証していません。

## 今回は動かさない機能

`check_extension` と `compare` は `unsupported_profile` と `operation_not_implemented` を返します。query の依存閉包に definitions/inclusions があれば `definition_reasoning_not_implemented` として unassessed にします。未実装の定義を読み飛ばして、原入力の検索結果を完全な推論結果と称しません。

したがって S1/S2 の自動認定・定義による導出、射影前後の差分計算は未実装です。実 CPC/FHIR の移行、一般の量化・確率・古典論理の否定推論も対象外です。P0 全体の 22/22 合格とはしません。

## 再現コマンド

リポジトリのルートで実行します。外部パッケージのインストールは不要です。

```bash
PYTHONPATH=src python3 -m med_dsl --fixture examples/p0/linked-observations.json
PYTHONPATH=src python3 -m med_dsl --fixture examples/p0/assertion-revision.json
python3 -m unittest discover -s tests
```

CLI は `0=正常処理、2=入力不正、3=未対応プロファイル/操作、4=資源上限` です。正常処理でも個別の query が unassessed の場合があるため、status と incomplete を確認します。

実行結果 JSON、unittest の出力、実行したソースとテストの SHA-256 は Git 管理外の `data/research/p0-a/` に記録しました。ソースの束のハッシュは、`src/med_dsl/*.py` と `tests/*.py` の相対パス→生バイト SHA-256 の対応を、キー順・空白なし JSON にして SHA-256 を計算します。実装コミットはこの文書とコードを含む履歴で特定できます。
