## 4. 変異検査（draft-2、全 112 件）

対象は、初版の108変異と、予算の退行を想定した4変異（B0〜B3）の計112件です。検出の層は三つで、(1) 従来の機能テスト（実体 hash を固定するだけの評価系18件は除く）、(2) 従来の117例の必須パス、(3) 追加系列（負例・draft-2・境界・予算掃引。manifest と束を突き合わせるだけのテストは除く）です。**P0 の5ファイルを変異させる場合は、変異後の木で hash を再固定してから検査**し、固定の崩れだけで検出したことにしません（初版では、この区別がなく6件が「固定経由でのみ失敗」でした）。

| 結果 | 件数 |
| --- | ---: |
| 検出（従来の層のどれか） | 79 |
| 検出（**追加系列だけ**） | 20 |
| 未検出 | 13 |
| 合計 | 112 |

初版で機能的に未検出だった33件のうち**20件**（H07、H11、H12、H25、P02、P03、P04＝RV-01 の7ゲート、ほかに H20、E18、E19、E20、Q03、Q04、Q07、D04、D08、V03、R06、R09、F12＝RV-07）を、追加系列が検出しました。予算の退行 B0〜B3 は従来のテストと予算掃引の両方が検出し、掃引だけが検出する退行は示せていません。

未検出の13件はすべて、**等価（到達しない・他の検査と二重）と判断**しました。この判断は私の内部判断で、外部レビューでの確認対象です（§6）。

| 変異 | 等価と判断した理由 |
| --- | --- |
| H01 | `not outside` は冗長。範囲外の問いがあると実行照合が `partial` になり、`matched` にならない |
| H02 | 中間の履歴往復は、最終の履歴往復と「第二段は改名だけ」の検査から従う |
| H05、H06 | 段の接続検査は、各段の票が実体の再計算値と一致する検査（RN03〜RN05 が単独で検出）から従う |
| H08 | 中間と最終は同じ履歴・同じ問いの比較で、`matched` が食い違わない（all／any が同値） |
| H19 | 実行照合の打切りを例外にする分岐。直後の確定の step で同じ打切りが再発する |
| E14 | 打切り時の `unassessed` は、未評価の行が必ず存在するため冗長 |
| E16、E17 | 左右どちらかの衝突を比較不能にする二重の防御。**両方を外すと**従来のテストと私の乱数検査の双方が検出する |
| E24 | 事象の基礎に旧関係の事実を残す分岐。展開後の問いは旧関係を参照しない |
| R03 | 証明と反例の矛盾を検出する自己点検。健全なら発火しない |
| P06 | 正規化 JSON の往復は常に成立する |
| F08 | 4096 bit の上限は到達しない（`test_the_4096_bit_intermediate_limit_is_unreachable_under_the_input_limits`） |

## 8. 結論（対象範囲付き）

1. 今回の範囲と手法では、**S0 に当たる事象は見つからなかった**。初版の S1（RV-01）と S2（RV-02〜07）はすべて処理し、未解消の S0／S1 はない。これは網羅の証明ではない。
2. 計画 §7 の合格条件（全 PO の判断と証拠、未解消 S0／S1 なし、再現と正例・負例、認定範囲の説明の一致）は、**内部の単独実施としては満たした**。ただし**独立性がないため、独立レビューの合格とは数えない**。`independent_review`／`evaluation_frozen` は false のまま。
3. 保証対象は「`p0-draft-2` の実装が、記載の有限領域と乱数照合の範囲で、AI-001 が書き直した参照計算・追加した負例・変異検査と矛盾しなかった」ことまで。体系の永続性、一般の保存判定、無限更新、臨床妥当性、Python 3.11 での実行には及ばない。参照計算は文書の定義に従うため、定義自体の誤りは検出できない。
4. 内部で了承した事項（兼任、RV-05 の裁定、profile の維持、等価変異の分類、PO の内部判定）は、§6 のとおり外部レビューで覆り得る。覆っても、draft-1（e73d4ba）へ戻れる。
5. 未確認点：独立の確認者、Python 3.11・他OS、417必須パスの人手再導出、領域3以上の参考意味、形式証明、P0 比較（`compare.py`）の変異、事象の `split_roles` 診断経路の乱数検査。
