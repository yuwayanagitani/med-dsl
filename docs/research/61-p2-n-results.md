## 4. 実験

### E1 元の断片の変更（N6）

P2-g の `matched_context` の判定（`measurement.py` の `_assess`）を、断片の中で一つずつ壊した木で、全宣言を登録し直し、P2-m と P2-g の差分の検査（324対）を実行しました。

| 壊し方 | 元の登録 | 継承する側の登録 | 差分の検査 |
| --- | --- | --- | --- |
| d1 `different_method` を出さない | 拒否（防護例） | 解決できず拒否 | 失敗 |
| d2 `different_specimen` を出さない | **登録される** | **証人が拒否** | 失敗 |
| d3 `different_property` を出さない | **登録される** | **証人が拒否** | 失敗 |
| d4 specimen／method の ref だけを比べ、version を見ない | 拒否（防護例） | 解決できず拒否 | 失敗 |
| d5 `different_subject` を出さない（断片の外） | 登録される | 影響なし | 一致（対照） |
| d6 最初の差だけを出す | **登録される** | **登録される** | **失敗**（差分の検査だけが捕まえる） |

P2-m の段階では、これらはいずれも差分の検査（テスト）だけが捕まえていました。継承を宣言すると、d2・d3 は**登録の時点で**捕まります。d6（複数の差が同時にあるとき）は、証人が単一の差の例しか持たないので、証人でも元の防護例でも捕まらず、全数の差分の検査だけが捕まえます（証人は差分の検査の代わりにならない）。予測では d4 を「元は登録され、証人が捕まえる」としましたが、P2-g の防護例が version の比較を覆っていて、外れました。

### E2 疑いの探索（N8）

| 版 | 疑いの組 | 宣言した継承の組に対する再現率 | 適合率 |
| --- | --- | --- | --- |
| 共通の語彙も数える（3定数以上） | 104 / 150 | 5/7 | 約0.05 |
| 二つの拡張だけが共有する定数（2以上） | 6 / 150 | 5/7（0.71） | 5/6（0.83） |

見つけた5組は、P2-m ← P2-g、P2-j ← P2-h、P2-i ← P2-g、P2-k ← P2-e、**P2-f ← P1（予測外）**。偽の疑い1組は P2-m と P2-j で、同じ親（P2-i）を呼ぶための語彙の共有でした。見逃した2組は P2-i ← P2-e（期間の分類）と P2-g ← P2-e（可視性）で、語彙が違う、または定数にならない規則です。2番目の版は、既知の継承を見た後で調整したので、適合率の高さは**未知の継承の検出力の見積りではありません**。

### E3 契約の版の更新（N7・N9）

draft-1 → draft-2 を、版の手順（旧版を履歴から再現し、旧入力は黙って再解釈されず、差は宣言した変更だけ）で検証しました。旧い宣言20件は全て新しい registry に拒否され（旧入力を黙って再解釈しない）、新しい宣言との差は宣言した2項目だけ、旧い木の列挙はその木の registry で行えて（`measurement.py` の変更で2件。新しい registry では5件）、P2-l の記録の検証が再び通ります。

## 5. 分かったこと

1. **継承は宣言に書けて、半分は登録時に確かめられる。** 9項目のうち7項目に、既存の例だけで証人が付いた（30証人）。欠落の2項目は、構造的に等しい例の組がないという理由が宣言に残る。
2. **欄を必須にしただけでは、書かれなかった継承は出てこない。** 予測外の1件を見つけたのは疑いの探索で、設計文書の読み直しではない。探索は、語彙の共有というヒューリスティックで、見逃しもある（7組のうち2組）。未宣言の継承を機械的に排除する手段はない。
3. **証人は単一の差を覆うが、組み合わせを覆わない。** d6 のように、断片の中の相互作用（複数の差が同時にある）の変更は、証人にも元の防護例にも捕まらず、全数の差分の検査だけが捕まえた。登録時の証人は、差分の検査の代わりではなく、早い警告である。
4. **継承の辺は、再検証の範囲を広げる。** P2-e の `temporal.py` の変更が列挙する拡張は1件から7件に、P1 の予測の変更は1件から7件になった。これは過大ではなく、これまで見えなかった結合を表す。一方、独立な組は150から143に減り、「独立」の意味が、構造の独立から、構造と意味の独立に変わった。
5. **契約の版が変わると、版の道具は旧い木を旧い実装で扱う必要がある。** 作業ツリーの registry に旧い木の宣言を渡す道具は、書式の更新で失敗した。P2-d の V2（旧版は旧版の契約で再現）の原則は、版の比較の道具自体にも要る。
6. **手で保つ一覧がまた一つ見つかった。** 契約の検査が、拡張ごとの前提の拡張を手で書いた一覧で保っていた。継承を足すと、その一覧が35件の誤りになった。宣言の依存と継承から求める形に直した（F4・F6 に続く三つ目の、一覧を内容から求める修正）。
7. **偽りの宣言は検査できない。** 証人が一致することは、再述の存在を示さない。継承がないのに宣言すること、継承があるのに宣言しないことは、機械的には排除できない。

## 8. 限界と次

- 証人は、既存の例の組が構造的に等しいことを、私が入力から選んだものです。選び方に誤りがあれば、一致しない（今回は30組が一致）か、一致しても意味のない一致になり得ます。
- 継承の関係は一種類（断片での観測の一致）です。差を伴う継承（精密化の追加）や、同じ拡張の版の間の継承（P2-l の VR-1）は、この欄の対象外です。
- 宣言した9項目は、私が設計文書と探索で挙げた範囲です。20宣言のうち14宣言は `inherits: []`（継承なし）を明示していますが、これは私の判断であり、独立の確認はありません。
- 設計者・実装者・検査の作成者が同一で、独立確認はありません。
- 次の候補は、複数の出力先への射影（C7）、実資料評価と薄い臨床ライブラリの試作範囲の選定、継承の関係の拡張（差を伴う継承、版の間の継承）です。着手前に利用者の確認を取ります。独立確認は将来の英語の別リポジトリで行います。
