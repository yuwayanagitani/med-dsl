# P2-u：用語の版更新の監査の実行例

[設計82](../../docs/research/82-p2-u-design.md)・[手指定期待83](../../docs/research/83-p2-u-cases.md) を88 JSON・1,679必須パスへ展開した、架空データだけの作成者草案です（87例を実装前に固定し、U27の1例は実装中に足しました）。独立確認・評価用正解の凍結は未実施です。現在の結果と制限は [内部評価84](../../docs/research/84-p2-u-results.md) に記録します。実データ（RxNorm CPC の2版）の語・ID は含みません。

旧版と新版の正規化した snapshot（概念＝出典と id、原子＝id・種類・名称・属性、関係＝種類と対象）と、比較する出典、属性の方針（宣言）、監査する参照を受け、**参照ごとに**、新版で同じ (出典, id) が続くか、続くなら名称・関係・属性の三つの面に何の差があるかを報告します。新版にない参照は、後継を決めず候補も出さず、公式の履歴を求める依頼を返します。差のあった属性が方針に宣言されていなければ、分類せず依頼にします。一方向（旧→新）で、逆向きは推定しません。

```bash
PYTHONPATH=src python3 -B -m med_dsl --fixture examples/p2-audit/u03.json
PYTHONPATH=src python3 -B -m med_dsl --fixture examples/p2-audit/u10.json
python3 -B -m unittest discover -s tests/p2 -p test_audit.py -v
```

- U01・U19・U21・U26：差のない参照（`unchanged_in_scope`）。使われない宣言は痕跡を残さない（U19）、並びを替えても同じ（U21）、版の識別子をそのまま出す（U26）。
- U02・U03・U15・U17・U18・U20・U25：属性の差。管理上の属性だけ（`changed_administrative_only`）、定義にあたる属性（`changed`。同じ ID が続いても意味の同一ではない）、値の集合（U15）、名称の差が優先（U17）、未宣言の差が管理上の差に優先して依頼（`needs_information`、U18・U20）。
- U05・U06・U16：名称の差（原子の追加・名称の変更・原子の削除。削除された原子の属性は属性の差に数えない）。
- U07〜U09・U12・U13・U24：関係の差。除去された関係の対象が新版にも残るか（U08）、対象も消えたか（U07）、追加された関係の対象が新しい概念か（U09）、新版で未解決になった対象（U13）、旧版でも未解決の既存の状態（U12）、入れ替え（U24）。
- U10・U23・U27：新版にない参照（`not_found`、`successor: not_determined`）。同じ名称・属性・関係の別の ID の概念が現れても候補にしない（U10）。出典が変わった同じ ID は別の概念（U23・U27）。
- U11・U22：比較範囲の外の出典の参照は比較せず（`not_compared`）、範囲に入れれば比べる（U22）。U14：U03 の入れ替え。
- N01〜N12：型・版・方針・参照・snapshot の形・重複・上限・予算。別の用語の組（N05）と同じ版の組（N06）は拒否。入力不正は予算に依らず同じ結果です。
- B01・B02：共通予算。参照ごとに料金を先払いし、最後の確定1を払うまで集計を返しません。標準は M＝30（U01）。

[manifest.json](manifest.json) は全ファイルのバイト数・sha256、各 fixture は手指定の required_paths 期待を持ちます。項目の数は [テスト](../../tests/p2/test_audit.py) が独立な別計算（集合の演算）の全数と乱数で確かめます。[生成器](../../scripts/research/p2/gen_audit_fixtures.py) は native を import せず、状態・差・依頼・集計・料金を手指定して展開します。生成するとJSONと台帳を書き換えるため、再現検査はコピーした木で行います。医学的な意味・置換の安全性は評価していません。
