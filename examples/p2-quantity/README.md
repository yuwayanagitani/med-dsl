# 量リテラルの厳密換算と有限区間比較（P2-f）

[意味設計](../../docs/research/34-p2-f-design.md)・[手指定期待](../../docs/research/35-p2-f-cases.md) に基づく架空の実行例です。[台帳](manifest.json) は **79 JSON・609必須パス**を管理します。Q24件、N43件、B12件で、P0/P1や他のP2系列とは別の分母です。[実装・内部評価](../../docs/research/36-p2-f-results.md) を参照してください。

| 系列 | 内容 |
| --- | --- |
| Q01〜Q08 | 点・負数・未約分・開閉区間の厳密換算 |
| Q09〜Q16 | 大小・交差・接触・同一参照と別参照の区別 |
| Q17〜Q20 | 無次元量、同じ次元でも異なる量種、次元不一致 |
| Q21〜Q24 | 未知の単位・量種・能力の停止、AI由来の保持 |
| N01〜N11 | 分母・型・63bit・区間・欄・未対応・消費側仕様・参照・件数の境界 |
| B01〜B04 | 予算0、換算8、比較12、同一参照比較11、二換算14と部分完了 |

設計のN12は既存出力の比較・順序・変異のテストで確認するため、単独のJSONはありません。N06の小数・NaN等もAPI・生JSONのテストで補います。丸め表示と字句の精度の反例D01/D02は設計資料として保持し、runtimeの成功件数に足しません。

```bash
PYTHONPATH=src python3 -B -m med_dsl --fixture examples/p2-quantity/q07.json
python3 -B -m unittest discover -s tests/p2 -p test_quantity.py -v
```

点・有限非空区間の数学的な計算に限定します。7単位・5量種は仕様hash内の架空の局所名です。測定の不確かさは未評価のまま保持し、数値の一致を臨床的同等性や基底の支持へ変換しません。`--fixture` が処理するのはrequestだけで、expectedは推論に渡しません。独立確認・評価用正解の凍結は未実施です。
