# 実装の配置候補

まだパッケージや実装はありません。TypeScript を候補としつつ、最初の試作範囲を決めてから実行環境を選びます。

| ディレクトリ候補 | 責務 |
| --- | --- |
| `ast/` | 中間表現と変換結果の型・スキーマ |
| `ontology/` | 概念参照、関係、臨床知識モデルの境界 |
| `adapters/` | 外部マスターの取り込みと参照 |
| `compiler/` | 対応規則の適用、意味の喪失・追加と根拠の生成。監査部分を分けるかは今後検討 |
| `typechecker/` | 構造・意味制約・参照の検証 |
| `parser/` | 将来必要になった場合の DSL 構文解析 |
| `cli/` | 限定したコード変換を試す入口 |

最初からすべてを独立パッケージにせず、試作に必要な部分から配置します。
